## 主标题

```md
文字 + 回车 + `==`（两个`=`或以上）
```

## 副标题

`#`号个数越多标题越小

```md
# 文字

## 文字

### 文字

#### 文字

##### 文字

###### 文字
```

## 区块

<div>
<p>```java</p>
<p>private void get(){</p>
<p>}</p>
<p>```</p>
</div>

或者四个空格 `+` 内容
或者四个空格 `+>`内容

## 多层引用

```md
> 内容
>
> > 内容
> >
> > > 内容
```

## 强调

```md
_内容_ 斜体
**内容** 粗体
**_内容_** 斜体加粗体
~~内容~~ 删除线
`内容` 行内代码
```

## 换行

在需要换行的地方输入至少两个空格 然后回车

## 链接

```md
[XXX](http://xxx)
```

或者

```md
[AA][1]
[BB][2]
[1]:http://xxx
[2]:http://xx
```

使用`[x]`:先定义链接地址，然后通过 x 作为代号引用。通常定义在顶部或底部

```md
<邮箱地址> 邮箱链接
```

## 图片

```md
![图片](http://xxx '鼠标悬停文字(可选)')
```

中括号里为图片的替代文字，括号里为图片网络地址

## 分割线

```
***

或 ---
或 - - - -
```

## 列表

```
* 一列
* 二列
```

或者

```md
- 一列
- 二列
```

多重直接前面加个缩进

## 表格

`|`对每一个格子分开，`:----`靠左，`:----:`居中，`----:`靠右

```md
| 身高 | 体重 | 胸围 |
| :--- | :--: | ---: |
| 180m | 70kg |  190 |
```
