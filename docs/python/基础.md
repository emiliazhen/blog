### 按位运算符

按位运算符把数字看做二级制来进行计算。

```python
a = 60 # 0011 1100
b = 13 # 0000 1100
a & b # 按位与：如果两个相应位都为1,则该位的结果为1,否则为0。输出结果12，因为0000 1100
a | b # 按位或：只要对应的二个二进位有一个为1时，结果位就为1。输出结果 61，因为0011 1101
a ^ b # 按位异或：当两对应的二进位相异时，结果为1。输出结果49，因为0011 0001
~a # 按位取反：对数据的每个二进制位取反,把1变为0,把0变为1。输出结果-61，因为1100 0011
a << 2 # 左移动：运算数的各二进位全部左移若干位。输出结果240，因为1111 0000
a >> 2 # 右移动：运算数的各二进位全部右移若干位。输出结果 15，因为0000 1111
```

### 遍历技巧

在字典中遍历时，关键字和对应的值可以使用 items() 方法同时解读出来。

```python
knights = {'Google': 1234, 'Baidu': 5678}
for k, v in knights.items():
   print(k, v)
```

在序列中遍历时，索引位置和对应值可以使用 enumerate() 函数同时得到。

```python
for i, v in enumerate(['Aa', 'Bb', 'Cc']):
   print(i, v)
# 0 Aa
# 1 Bb
# 2 Cc
```

同时遍历两个或更多的序列，可以使用 zip() 组合。

```python
questions = ['name', 'age']
answers = ['Tom', '30']
for q, a in zip(questions, answers):
   print('What is the {0}?  It is {1}.'.format(q, a))
# What is the name?  It is Tom.
# What is the age?  It is 30.
```

要按顺序遍历一个序列，使用 sorted() 函数返回一个已排序的序列，并不修改原值。

```python
basket = ['apple', 'orange', 'apple', 'pear', 'orange', 'banana']
for f in sorted(set(basket)):
   print(f)
# apple
# banana
# orange
# pear
```
