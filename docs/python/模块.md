## 模块

一个.py文件就称之为一个模块（Module）
使用模块可以大大提高了代码的可维护性，而且当一个模块编写完毕，就可以被其他地方引用。
我们在使用python完成很多复杂工作时，也经常引用其他第三方模块。

### import 语句

```python
import myTools

myTools.max(1,3)
```

### from … import 语句

```python
from fibo import fib, fib_new
fib(50) # 1 1 2 3 5 8 13 21 34
```

```python
from fibo import *
fib(50) # 1 1 2 3 5 8 13 21 34
```

### 包

在导入一个包的时候，Python 会根据 sys.path 中的目录来寻找这个包中包含的子目录。
目录只有包含一个叫做**init**.py 的文件才会被认作是一个包。

```
video/
    __init__.py
    audio/
        __init__.py
        io.py
        fx.py
    editor/
        __init__.py
        faster.py
        slower.py
```

用户可以每次只导入一个包里面的特定模块

```python
import video.audio.io
video.audio.io.readfile(input)
```

这同样会导入子模块: io，并且他不需要那些冗长的前缀

```python
from video.audio import io
io.readfile(input)
```

直接导入一个函数或者变量

```python
from video.audio.io import readfile
readfile(input)
```
