## 文件目录操作

在开发中对文件进行读取、遍历、修改等操作，通过 python 的标准内置os模块，能够以简洁高效的方式完成这些操作。

### 查询操作

| 方法名  | 说明               |
| :------ | :----------------- |
| listdir | 文件及目录列表     |
| getcwd  | 获取当前目录       |
| chdir   | 更换目录           |
| stat    | 文件及目录基本信息 |
| walk    | 递归遍历目录       |

stat函数返回的基本信息

| 属性名   | 说明                       |
| :------- | :------------------------- |
| st_mode  | inode 保护模式             |
| st_ino   | inode 节点号               |
| st_dev   | inode 驻留的设备           |
| st_nlink | inode 的链接数             |
| st_uid   | 所有者的用户ID             |
| st_gid   | 所有者的组ID               |
| st_size  | 普通文件以字节为单位的大小 |
| st_atime | 上次访问的时间             |
| st_mtime | 最后一次修改的时间         |
| st_ctime | 创建时                     |

### 遍历操作

walk 函数对目录进行递归遍历，返回 root，dirs，files，分别对应当前的遍历的目录、此目录中的子目录和文件。

```python
data = os.walk("test")               # 遍历test目录
for root,dirs,files in data|        # 递归遍历及输出
   print("root:%s" % root)
   for dir in dirs:
      print(os.path.join(root,dir))
   for file in files:
      print(os.path.join(root,file))
```

### 创建操作

mkdir ：新建单个目录，若目录路径中父目录不存在，则创建失败
makedirs ：新建多个目录，若目录路径中父目录不存在，则自动创建

### 删除操作

rmdir ：删除单个空目录，目录不为空则报错
removedirs ： 按路径删除递归多级空目录，目录不为空则报错

> 由于删除空目录的限制，更多的是使用 shutil模块中的 rmtree函数，可以删除不为空的目录及其文件。

### 修改操作

rename ：重命名目录或文件，可修改文件或目录的路径（即移动操作），若目标文件目录不存在，则报错。
renames ：重命名目录或文件，若目标文件目录不存在，则自动创建

## 文件操作

### 查询操作

open/read/close ：文件读取
stat ：文件信息

```python
f = os.open("test/test.txt", os.O_RDWR|os.O_CREAT)  # 打开文件
str_bytes = os.read(f,100)                          # 读100字节
str = bytes.decode(str_bytes)                       # 字节转字符串
os.close(f)                                         # 关闭文件
```

参数可以是以下选项，多个使用 “|” 隔开

| 选项       | 说明                                           |
| :--------- | :--------------------------------------------- |
| O_RDONLY   | 以只读的方式打开                               |
| O_WRONLY   | 以只写的方式打开                               |
| O_RDWR     | 以读写的方式打开                               |
| O_NONBLOCK | 打开时不阻塞                                   |
| O_APPEND   | 以追加的方式打开                               |
| O_CREAT    | 创建并打开一个新文件                           |
| O_TRUNC    | 打开一个文件并截断它的长度为零（必须有写权限） |
| O_EXCL     | 如果指定的文件存在，返回错误                   |
| O_SHLOCK   | 自动获取共享锁                                 |
| O_EXLOCK   | 自动获取独立锁                                 |
| O_DIRECT   | 消除或减少缓存效果                             |
| O_FSYNC    | 同步写入                                       |
| O_NOFOLLOW | 不追踪软链接                                   |

### 创建操作

使用open创建文件，指定模式， 若文件不存在，则创建。有点类似 linux 操作中的 touch。

```python
f = os.open("test/a.txt", os.O_RDWR|os.O_CREAT)   # 若文件不存在，则创建
os.close(f)
```

### 修改操作

open/write/close ：写入文件内容
rename，renames ： 修改名称、移动操作。

### 删除操作

remove ：删除文件，注意不能删除目录（使用 rmdir/removedirs）
remove ：删除文件，注意不能删除目录（使用 rmdir/removedirs）

## 路径操作

os 中有一个子模块 path，处理路径操作。
abspath ：返回绝对路径
exists ：判断文件或目录是否存在
isfile/isdir ：判断是否为文件/目录
basename/dirname：获取路径尾部和路径头部。其实就是以路径中最后一个 / 为分割符，分为头（head） 和尾（tail）两部分，tail 是 basename 返回的内容，head 是 dirname 返回的内容。经常用于获取文件名，目录名等操作
join ：合成路径，即把两个参数使用系统路径分割符进行连接，形成完整路径。
split ：分割文件名和文件夹，即把 path 以最后一个斜线”/“为分隔符，切割为 head 和 tail ，以 (head, tail) 元组的形式返回。
splitext ：分割路径名和文件扩展名，把path 以最后一个扩展名分隔符“.”分割，切割为 head 和 tail ，以 (head, tail) 元组的形势返回。注意与 split 的区别是分隔符的不同。
