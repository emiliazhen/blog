## 分支结构

- if
- switch

> [!tip]  
> switch 表达式类型只能是 byte、short、int、char，JDK5 开始支持枚举，JDK7 开始支持 String，不支持 double、float、long

## 循环结构

- for

```java
for(int i = 0; i < 5; i++){
  System.out.println(i);
}
```

- while

```java
int i = 0;
while(i<5){
  System.out.println(i);
  i++;
}
```

- do.while

```java
int i = 0;
do(i<5){
  System.out.println(i);
  i++;
} while(i < 5)
```
